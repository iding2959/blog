# blog.952405.xyz

基于 **Hexo 7** + **Fluid 主题** 的个人技术博客。

## 本地开发

```bash
npm install       # 安装依赖
npm run server    # 启动本地预览 → http://localhost:4000
npm run build     # 生成静态文件到 public/
npm run clean     # 清除缓存和生成文件
```

## 新建文章

```bash
npx hexo new "<文章标题>"
```

文章存放在 `source/_posts/` 下，按子目录分类（backend / frontend / tools / tutorial / others）。

## 技术栈

- [Hexo 7](https://hexo.io)
- [Fluid 主题](https://hexo.fluiddocs.com)
- 部署至 blog.952405.xyz
